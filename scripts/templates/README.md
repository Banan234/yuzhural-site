# Покупательский прайс

`buyer-price.xlsx` — оформленный шаблон, созданный в Artifact Tool. Лист «Прайс»:
строки 2–5 содержат заголовок и контекст, строка 6 — заголовки таблицы,
строка 7 — образец стилей девяти колонок. Таблица `BuyerPrice` имеет фильтры;
первые шесть строк закреплены.

`scripts/lib/buyerPrice.js` заполняет OOXML внутри шаблона, сохраняя оформление,
таблицу, числовые форматы и закрепление. Значения записываются как числа либо
литеральный текст, без исполнения формул из названий. Все предложения сохраняются
отдельными строками. Для `pending` цена, остаток и единица остаются пустыми.

Каждый успешный импорт публикует `price-buyer.xlsx` в одной транзакции с каталогом
и исходным `price.xls`. Runtime-сборка переносит этот же файл; при первом запуске
на старом выпуске создаёт файл из каталога, явно подписывая дату файла каталога.

Для локального обновления файла в `public/`:

```sh
node scripts/buildBuyerPrice.js
```

Можно передать другой путь назначения первым аргументом. Исходный XLS не меняется.
