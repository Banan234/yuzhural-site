# Тестовые варианты ВВГ 3×1,5

Созданы встроенным imagegen по скриншотам пользователя как примерам ракурса и предметной подачи. Это иллюстрации конструкции, не фотографии конкретного товара или производителя. Все PNG имеют прозрачный фон, 1536×1024.

| Файл | Ракурс |
| --- | --- |
| `vvg-3x1-5-from-right.png` | Оболочка входит справа, разделка направлена влево |
| `vvg-3x1-5-from-left.png` | Оболочка входит слева, разделка направлена вправо |
| `vvg-3x1-5-from-lower-right.png` | Оболочка входит из правого нижнего угла |
| `vvg-3x1-5-from-lower-left.png` | Оболочка входит из левого нижнего угла |

## Промпт

Общее для всех вариантов: новый предметный 3D-рендер кабеля ВВГ 3×1,5 для карточки каталога, прозрачный PNG; матовая круглая чёрная оболочка ПВХ; ровно три жилы с коричневой, синей и жёлто-зелёной изоляцией и короткими открытыми концами цельной медной жилы; правдоподобные пропорции; без надписей, логотипов, водяных знаков, интерфейса, лишних объектов и жил. Первый вариант опирается на скриншоты пользователя как референсы подачи, остальные — на первый рендер для единообразия.

Различия промптов: (1) вход справа и концы слева, почти горизонтально; (2) вход слева и концы справа с лёгким наклоном вниз; (3) диагональ из нижнего правого угла к верхнему левому; (4) диагональ из нижнего левого угла к верхнему правому.

Перед публикацией как изображения конкретной позиции нужно сверить конструкцию, цвета и внешний вид с реальным товаром.
