# Ручная ревизия кабельных PNG

Запустите сервер из корня проекта.

```sh
npm run images:cables:gallery -- --port 4179
```

В [ревизии референсов](http://127.0.0.1:4179/reference-review) собраны PNG с
действующим разрешением на использование в запросах. Счётчик показывает SKU,
у которых галерея подтвердила использование PNG в каталоге. Для старых
групповых изображений без записанного исходного SKU показан представитель
из сохранённой группы. Четыре защищённых эталона доступны для просмотра.

Отметьте «Оставить» или «Переделать» и внесите замечания. Повторное нажатие
снимает отметку. Браузер сохраняет решения и замечания по SHA-256. Чтобы
вернуться к ним, используйте тот же профиль браузера и адрес с тем же портом.
Кнопка «Скачать список „Переделать“» выгружает отмеченные PNG и замечания в JSON.
«Обновить из реестра» перечитывает разрешения и привязки. Отметки ревизии
хранятся локально в браузере и не участвуют в подборе референсов.

Откройте [галерею](http://127.0.0.1:4179/). В рабочем режиме выберите группу
без изображения и нажмите «Подобрать или создать PNG». Команда сначала
проверяет готовые утверждения. Подтверждайте платный запрос только после
отдельного согласования генерации. Проверьте новый PNG и сохраните решение.
«Утвердить и разместить» применяет штатную привязку к доступным совместимым
SKU. Допуск к генерации выдаётся отдельно через «Роль референса».
Для нового варианта сохраните решение «Требует исправления» с причиной,
откройте карточку и нажмите «Создать исправленный PNG».

Для исторических PNG и отчётов запустите галерею с `--archive`.
Этот режим читает прежние выпуски и ZIP через системную команду `unzip`.
Рабочий режим читает реестр, назначения и известные черновики. Сведения о
прежних платных попытках перенесены в
`data/product-image-metadata/historical-generation-claims.json`. На снимках
без этого файла действует прежнее чтение. Пересканирование подхватывает
сохранённые изменения из других процессов.

Одна карточка соответствует одному SHA-256. В ней перечислены сохранённые копии, старые решения, референсы из метаданных, действующие SKU и совместимость по конкретным visualKey. Совпадение имени или семейства само по себе не подтверждает совместимость. «Целостность» показывает файлы и записи, которые не прошли проверку.

Для пакетной операции отметьте PNG и откройте «Пакетное решение». Выбор сохраняется при переходе между страницами. Утверждение черновика требует ручных проверок для каждого PNG. Сохранение пакета отклоняется целиком, если хотя бы у одной записи устарела ревизия или отсутствует необходимое подтверждение.

Журнал `reviewBySha256` хранится в `data/cable-approved-results/registry.json`. Отмена добавляет новое событие. Экспорт переносит журнал решений галереи, включая его хеши. Для импорта нужны исходные PNG и, для положительных решений, соответствующие утверждения в постоянном реестре. Если история разошлась, сверяйте прежние решения в карточке и разрешайте конфликт вручную.

«Основной референс» получает приоритет среди подходящих кандидатов. Обязательное совпадение геометрии и четыре защищённых стилевых эталона определяются действующими правилами конвейера. Отклонение и отправка на исправление блокируют будущий автоматический подбор и повторное назначение. Изменение уже применённого назначения выполняется по отдельной процедуре каталога.
