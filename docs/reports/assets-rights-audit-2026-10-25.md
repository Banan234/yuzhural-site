# Проверка происхождения и лицензий материалов — 25.10.2026

Проверены локальные файлы и ссылки из кода. Это проверка документальных подтверждений в проекте, а не заключение об отсутствии любых прав третьих лиц. Файлы сайта не удалялись и не заменялись.

## Шрифты

- Активный шрифт сайта — Noto Sans: src/styles/core/fonts.css, src/styles/core/base.css. Локальные файлы и SIL OFL 1.1 находятся в public/fonts/noto-sans/; README содержит upstream и источник загрузки.
- Roboto используется для PDF коммерческого предложения в src/lib/quotePdf.js. Лицензия public/fonts/OFL-Roboto.txt присутствует.
- Для Arimo также приложена OFL; активным шрифтом сайта он сейчас не является.
- OFL допускает коммерческое использование и встраивание. Сохранять тексты лицензий при распространении файлов; отдельная платная лицензия для этих применений не требуется. Подлинность каждого бинарного файла по upstream-хешу отдельно не проверялась.
- Официальное разъяснение: https://openfontlicense.org/

## Кабельные иллюстрации

В data/product-image-metadata/production-v1/manifest.json — 565 групп: у 442 указан provider codex-sale; у 123 поле provider отсутствует. Это число записей манифеста, не число уникальных изображений и не число товаров.

Сохранены технические сведения генерации и проверки. Они не заменяют условия сервиса. Нужно сохранить условия коммерческого использования фактического сервиса генерации; для восстановленных записей установить происхождение. Название модели не доказывает прямое использование сервиса конкретного правообладателя. Сгенерированное изображение само по себе не гарантирует отсутствия чужих защищённых элементов.

Отдельно есть outputs/site-illustrations-2026-10-21/README.md и prompts.json с указанием встроенной генерации image_gen для трёх типовых сцен. Это подтверждает происхождение тех иллюстраций, но без сопоставления файлов не распространяется автоматически на все перечисленные баннеры.

Нужно уточнить: собственные фото/дизайн, генерация или сторонняя загрузка. Для сторонних материалов сохранить разрешение или лицензию. Для заказного логотипа — документ об условиях использования результата. Для генерации — исходник и сведения инструмента. Не выдавать типовой сгенерированный склад за документальное фото склада компании.

## Логотипы производителей

public/manufacturers/sources.json содержит источники девяти логотипов. Большинство — сайты производителей или их каталоги. Belden взят с logotyp.us, стороннего агрегатора. Ссылка на загрузку не является лицензией.

Проверить, что блок показывает действительно предлагаемые товары производителей и не заявляет неподтверждённый статус официального дилера или партнёра. Правомерность использования товарного знака зависит от контекста; нельзя объявить все логотипы запрещёнными или разрешёнными только по факту скачивания. Для Belden предпочтительно получить официальный исходник и проверить правила бренда.

## Иконки и заглушки

В проекте есть inline SVG и простые SVG-заглушки. Отдельная сторонняя библиотека иконок в проверенных зависимостях не обнаружена. Это не доказывает авторство каждого SVG; при заимствовании требуется сохранить источник и соответствующую лицензию.

## До публикации

1. Подтвердить происхождение баннеров и собственного логотипа.
2. Сохранить условия сервиса генерации кабельных изображений и выяснить происхождение записей без provider.
3. Уточнить контекст использования логотипов производителей; проверить Belden по официальному источнику.
4. Сохранить OFL вместе с поставляемыми файлами шрифтов.

Правовая основа для чужих изображений: ГК РФ, статьи 1229 и 1270; для товарных знаков — статьи 1484 и 1487. Это отдельная тема от обработки персональных данных по 152-ФЗ.
