# Справочник расчётной массы кабеля

`data/cableMassReference.json` содержит 4103 табличных значения массы 1 км и наружного диаметра для 89 марок из опубликованных каталогов и страниц семи изготовителей. Каждая строка сохраняет источник, страницу PDF или адрес карточки товара, полное обозначение марки, конструкцию и напряжение, если оно есть в таблице. Значения разных изготовителей не объединяются.

Источники: общий каталог [ХКА](https://uralcable.ru/catalog/print-catalog/) и его [таблица КГ](https://www.holdcable.com/catalog/spravochnaya-informatsiya/1395000/), каталог [Ункомтех](https://www.uncomtech.ru/download/366), технические страницы [Энергокабель](https://www.energokab.ru/katalog/provoda-i-kabeli-dlja-elektricheskih-ustanovok/marki-puv-pugv-puvv-pugvv-kuvv-kugvv-po-tu-16-705501-2010/pugvv/), каталог [Паритет](https://paritet.su/upload/catalog_transcab.pdf), каталог [Самарской кабельной компании](https://www.samaracable.ru/upload/catalog.pdf), карточки [Подольскабеля](https://podolskkabel.ru/catalog/kabeli-malogabaritnye/kmpv/) и таблицы [ГЕРДА-КВ/КВК](https://kazkabel.kz/wp-content/uploads/kek/2025/03/tablica-diametrov-gerda-kv-gerda-kvk.pdf) и [КУИН](https://kazkabel.kz/wp-content/uploads/kek/2025/03/tablica-diametrov-kuin-x2x-x3x-x4x-skr-redakciya-2018-08.pdf), размещённые на сайте «Казэнергокабеля». Для каждой технической страницы «Энергокабеля» и каждой включённой карточки «Подольскабеля» сохранена точная ссылка.

В список добавлены распространённые марки из нашего каталога: ВВГ, АВВГ, ВБШв, ВБбШв, АВБШв, КГ, КВВГ, КВБбШв, ПуГВ, ПуВ, ПВ1, ПВ3, КГВВ, КГВЭВ, исполнения КППГ и ППГ, МКЭШ, МКЭШВ, МКЭКШв, МКШ, МГШВ, ТППэп, СИП-2, СИП-4, четыре точных исполнения КПСнг(А)-FRLS, ГЕРДА-КВ/КВК и исполнения КУИН `ВЭ`/`ВЭК`. Это всё ещё не полный охват товарных позиций: если в таблице нет точной марки и конструкции, калькулятор не подменяет её похожей. Для КГВЭВ включены только строки с одной страницы каталога ХКА, где заголовок марки однозначен; продолжение таблицы с переплетёнными колонками не перенесено.

Следующее расширение добавило **20 новых марок**: КМПВ, КВКбШв, НВ, БПВЛ, МКШВ, БПДО, КУПЭВ, ПуГВВ, КМПВЭВ, КУПВ, КМПЭВ, КМПЭВЭВ, ВКбШв, РПШЭк, НВМ, МККШв, КВВ, МПО, НВЭВ и РПШк. Для каждой марки «Подольскабеля» отобрано до 12 карточек с массой и наружным диаметром, с приоритетом маркоразмеров, которые встречаются в нашем каталоге. Для ПуГВВ взяты 20 строк из [таблицы изготовителя](https://www.energokab.ru/katalog/provoda-i-kabeli-dlja-elektricheskih-ustanovok/marki-puv-pugv-puvv-pugvv-kuvv-kugvv-po-tu-16-705501-2010/pugvv/). Это выборка типоразмеров, а не все выпускаемые варианты этих марок.

Приоритет расширения определён по числу позиций с данной маркой в локальном `data/products.json` (5715 товаров), а не по продажам или поисковому спросу. Среди марок, которых прежде не было в калькуляторе: МКЭШВ — 112 позиций, МКЭКШВ — 86, КПС — 81 (в справочник добавлены точные исполнения `нг(А)-FRLS`), ВБбШв — 59, КВК — 55 (в справочнике указан изготовитель ГЕРДА), ППГ — 55 (только точные исполнения `нг(А)-FRHF`), КУИН — 49 (только `ВЭ` и `ВЭК`), МГШВ — 48, ТППэп — 46, МКШ — 38, СИП-2 — 29 и СИП-4 — 11. Написание строчной или прописной `в` в конце марки при подсчёте приведено к одному виду.

Для КПС из таблиц «Энергокабеля» включены однопарные исполнения: у двухпарных указан размер прямоугольного сечения, который нельзя честно показать в поле «диаметр». Для ГЕРДА-КВ/КВК включена выборка распространённых конструкций из первых четырёх страниц таблицы; значения не распространяются на исполнения `нг`, `нг(А)`, `FRLS`, `ХЛ` и кабели других производителей. Для КУИН взяты только табличные колонки `ВЭ` и `ВЭК` в сериях `нг(А)` и `нг(А)-FRLS`; значения нельзя переносить на варианты с другими материалами оболочки, экрана или с климатическим индексом `ХЛ`.

Для телефонных ТППэп запись вида `5х2х0,40` означает пять пар по две жилы с номинальным **диаметром жилы** 0,40 мм, а не сечением 0,40 мм².

У НВ и НВМ изготовитель указывает разные исполнения по ГОСТ 17515-72 для одинаковых сечений и напряжений. В справочнике исполнение сохранено в обозначении размера, например `0,50(НВ-1)` и `0,50(НВ-4)`; их массу нельзя взаимозаменять. Для других новых марок напряжение из карточки товара также сохранено отдельно.

На странице КВВГз есть две конструкции с повторяющимися обозначениями, но разными значениями массы и без признака, который позволил бы их различить. Эти четыре строки исключены из справочника.

Справочник служит для ориентировочного расчёта. Он не подтверждает массу партии на нашем складе; табличные значения не включают массу барабана, упаковки и крепежа. В калькуляторе можно отдельно прибавить массу одного барабана, умноженную на количество барабанов. У большинства товаров в `data/products.json` не указан изготовитель или напряжение; автоматически связывать такие товары со строками справочника нельзя.

`data/cableDrumReference.json` содержит справочные массы **22 деревянных и 6 металлических барабанов** из открытого [калькулятора «Кабельных систем»](https://kabel-s.ru/info/calc-kabel-ves/) (значения опубликованы в его `js_calc/calculatorV.js`). После выбора материала и номера калькулятор показывает массу одного барабана и учитывает выбранное количество в общем весе. Для нестандартной тары можно ввести фактическую массу вручную. В исходном JavaScript обозначения `186`, `206`, `226` записаны цифрами; в интерфейсе они показаны как `18б`, `20б`, `22б` согласно [каталогу барабанов на том же сайте](https://kabel-s.ru/catalog/kabel-nye-barabany/). Справочная масса может отличаться от фактической массы конкретной тары.

Чтобы обновить таблицу:

```sh
python3 -m pip install -r scripts/cable-mass-requirements.txt
python3 scripts/buildCableMassReference.py
```

Скрипт скачивает исходные документы в системный временный каталог и извлекает только явно настроенные таблицы. Для расширения на новые страницы нужно указать их в скрипте, проверить расположение заголовков и выборочно сверить строки с оригиналом PDF. В «Подольскабеле» включены только карточки с двумя подтверждёнными величинами; для многочисленных вариантов МКЭШВ выбраны стандартные сочетания сечений и числа жил. На странице 318 ХКА для ТППэп взяты только колонки со сплошной полиэтиленовой изоляцией; данные исполнения с плёнко-пористо-плёночной изоляцией не смешиваются с ними. На странице 6 каталога «Паритет» есть несколько значений, которые уменьшаются при увеличении числа жил; эти строки исключены до подтверждения издателем.
