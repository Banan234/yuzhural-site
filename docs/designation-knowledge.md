# База расшифровок обозначений

Версия заводских расшифровок `2026-10-17.8`; справочный и нормативный слой `2026-10-20.1` проверен 2026-10-20. База содержит 794 семейные записи и реестр 175 документов. Получены 145 документов: 133 заводских, 10 нормативных, один справочный и один вспомогательный дилерский. Корпус PDF содержит 5592 физических страниц. Заводское покрытие учитывает только подходящие полученные документы изготовителей. Наличие файла не означает ручную проверку всех его страниц.

Каждая семейная запись задаёт точное обозначение, описание, значения элементов, размерную величину и источник. Новые записи содержат `evidence.documentId`, физические страницы PDF и дату проверки. Конструктор КУМП позволяет сочетать описанные в нём экраны и броню. Такие комбинации основаны на правилах конструктора; самостоятельная проверка паспорта каждого SKU не выполнялась.

Короткие обозначения изготовителей и непроверенные продолжения марки не раскрываются по общему словарю букв. Например, КСБ — имя семейства. Диаметр и сечение задаются отдельными размерными типами. У КПЭТИ заводской ряд позволяет различить диаметр 0,5/0,7 мм и сечение 0,35 мм²; другие номиналы остаются на проверке. ПВКВ с силиконовой изоляцией отделён по регистру от силового ПвКВ. Документы описывают семейство и не подтверждают изготовителя складской партии.

## Применение к прайсу

Сначала выполнить просмотр:

```sh
node scripts/applyDesignationKnowledge.js --report /tmp/designation-preview.json
```

После проверки применить к локальному каталогу:

```sh
node scripts/applyDesignationKnowledge.js --apply --report /tmp/designation-applied.json
npm run build:prod
```

Операция использует блокировку импорта, создаёт резервную копию и публикует новую версию `data/catalog-current` через существующую атомарную транзакцию. К каждой позиции добавляется только `designationDecoded`; все исходные поля проверяются на полное равенство. Совместимый `data/products.json` обновляется той же транзакцией. Старый релиз сохраняется существующим механизмом каталога.

Все будущие импорты (локальный файл, удалённый прайс, загрузка через админку и плановый запуск) автоматически используют текущую базу. `classifyEligibleProducts` заполняет `designationDecoded`, а окончательный список после присвоения стабильных ID обогащается через `enrichPriceDesignations`. Перед публикацией `publishImportArtifacts` повторно применяет текущие правила, заменяя устаревшие расшифровки из входных данных. Новые SKU не требуют отдельного ручного запуска. В отчёт импорта добавляется `designationDecoding`, рядом с каталогом сохраняется `designation-coverage.json` с подсчётами и очередью нераспознанных позиций. Поле содержит версию базы, ID семейной записи, расшифровку, ссылки, нераспознанные элементы и предупреждения. API карточки сохраняет это поле. React и статический HTML используют общий построитель из `shared/productDesignation.js`, поэтому изменения справочника доступны при следующей сборке.

Статусы:

- `reviewed`: построитель нашёл семейство, распознанные атрибуты не вызвали замечаний.
- `partial`: семейство найдено, отдельные элементы или размеры требуют уточнения.
- `unresolved`: семейство не подтверждено. Показаны только независимо распознанные элементы.

Это статусы автоматического сопоставления; они не обозначают экспертную проверку партии.

`officialComplete` — отдельный строгий признак: нет неизвестных индексов и предупреждений, числовая конфигурация разобрана, единицы подтверждены и `evidence.documentId` ведёт на полученный документ изготовителя (`publisherType: manufacturer`). Простое совпадение семейства, сложные конфигурации, общие обозначения изготовителей и неполученные документы в этот счёт не входят. Для заводского PDF в стороннем облачном хранилище сохраняется `publisherProofUrl` со ссылкой на него на официальном сайте изготовителя.

В исторической редакции .4 от 2026-10-17 строгому критерию соответствовали 3997 из 5708 позиций — 70,02%. Остальные 1711 позиций перечислены в `officialPending`. Автоматические статусы: 4063 `reviewed`, 338 `partial`, 1307 `unresolved`. Статус `reviewed` сам по себе не подтверждает официальный источник. `officialCoverage` использует знаменателем весь прайс, а `officialByDocument` позволяет проверить вклад каждого документа. Это покрытие базы, а не оценка вероятности правильности и не независимая экспертиза. Цены, остатки, артикулы, URL и исходные наименования не меняются.

## Расширение

Добавлять сведения только по документации изготовителя: точное семейство, область действия исполнения, размерная величина и физические страницы. Для HTML указывать прямую страницу. Сохранять URL, дату получения и SHA-256 документа в реестре; недоступность отмечать отдельно. Полные PDF и текстовые выгрузки хранятся в исследовательской папке чата и не включены в репозиторий.

Сопоставление неизвестных марок с текстом документов создаёт очередь кандидатов для ручной проверки. Совпадение имени, числового артикула, таблицы аналогов или упоминания другого производителя не допускает автоматического включения в рабочие правила. После изменения базы обновить её версию, запустить тесты расшифровки и применения, проверить отчёт прайса и пересобрать HTML.

В версии .3 добавлены 14 доступных документов Камкабеля, Томсккабеля, Prysmian и Спецкабеля, 232 семейных правила. Варианты экранов ТОФЛЕКС КУ основаны на явно перечисленных заменах в конструкторе; они сохраняют положение группового и общего экрана. Суффикс напряжения принимается только для перечисленных бумажно-изолированных марок и значений из таблицы. Числовые серии ЛОУТОКС требуют контекста бренда; серия 20 измеряется сечением, 30 — диаметром. Концентрический проводник NYCY не подменяется металлическим экраном.

В .4 конструктор КУИН взят из документа по ТУ 3581-010-76960731-2008. КГтп имеет собственную конструкцию из термоэластопласта; HF-исполнение ТППэп получает безгалогенную оболочку из каталога Самарской кабельной компании. Исправлены назначение СКАБ, написание LTx у ЛОУТОКС, повтор пожарного индекса и опасный возврат к КММ при неизвестном полном обозначении КММЭф. Размер КПС 0,78 остаётся непроверенным.

Контрольный переимпорт в предыдущей редакции был остановлен ограничением изменения категорий (27,05% против 1%). Текущие расшифровки применяются отдельной операцией, сохраняющей все исходные поля; категории также сохраняются. Этот защитный контроль не отключён для будущих импортов. Достижение покрытия 70% не превращено в запрет добавлять новые неизвестные позиции: они попадают в очередь проверки.

## Альтернативная проверка, редакция 2026-10-17.5

Проверка группируется по базовому семейству, а не по каждому размеру, цвету или суффиксу. В `crossChecks` сохранены результат, конкретные проверенные признаки, ссылки на дополнительные документы и ограничения. Семейство ссылается на запись через `crossCheckId`. Декодер сохраняет в `designationDecoded.crossCheck` идентификатор, статус, дату и область проверки. `coversFullDesignation: false` означает, что проверка семейства не удостоверяет новый размер, специальное исполнение или изготовителя партии.

Из 305 семейных правил, используемых прайсом, содержательное сопоставление выполнено для 173 семейств (3648 позиций). Для 110 семейств (2936 позиций) перечисленные базовые признаки согласуются с документацией другого изготовителя. Отдельно учитываются документы того же издателя, связанные публикации ГЕРДА/Донкабель/Кубанькабель, частичные альтернативы и противоречия. Для оставшихся 132 семейств (618 позиций) поиск по корпусу не дал достаточного второго описания; индивидуальная исчерпывающая проверка интернета для них не заявляется. Ещё 1442 позиции не имеют конкретного семейного правила. Эти числа не являются оценкой вероятности правильности.

Разделены регистрозависимые ПвПГ и ПвПг: для низковольтного ПвПГ-HF применяются СПЭ-изоляция и безгалогенная оболочка, а не продольная герметизация средневольтной серии. Неподтверждённые номиналы КСВВ, КПСВВ/КПСВЭВ, КСРВ/КСРЭВ/КСРП получают предупреждение; одна пара КСВВ не смешивается с одной жилой. В КВИП единицы выбираются по документированным рядам диаметров и сечений. Базовая ПЭ-оболочка ПвП/АПвП не подтверждает материал HF-исполнения. Источник ELITRONIC заменён на технический лист TKD; для ППВ/АППВ добавлены конкретные заводские карточки.

После применения .5: 4006 из 5708 позиций (70,18%) соответствуют полному автоматическому критерию; 4055 имеют статус `reviewed`, 346 — `partial`, 1307 — `unresolved`. Проверка альтернативного источника сама по себе не повышает `officialComplete`. Подробный отчёт, новые предупреждения и сравнение до/после сохранены в исследовательской папке `outputs/alternative-source-audit-2026-10-17` чата.

### Заводские описания и назначение, ревизия 2026-10-17.6

`shared/manufacturerTexts.json` хранит массив отдельных заводских разделов: изготовитель документации, вид и заголовок раздела, краткое изложение технического содержания, документ, физические страницы PDF, SHA-256 оригинала, дата проверки, семейства и ограничения исполнения. Полный авторский текст читается в оригинале по ссылке; краткое изложение не выдаётся за дословную цитату. Оригинальные документы остаются в собранном исследовательском корпусе. Разные заводы и разные разделы одного завода сохраняются отдельно, даже если их назначения похожи. `manufacturer` внутри записи обозначает издателя документации, а не установленного изготовителя складской партии.

`designationDecoded.manufacturerTexts` автоматически заполняется общей функцией декодирования в текущем прайсе и во всех будущих путях импорта. Неизвестная марка не получает описание по совпадению начала строки. Базовое назначение семейства отделено от допуска конкретного размера и исполнения; оно не меняет `officialComplete`. Тексты с `firePattern` отбираются по исполнению. Изменение SHA оригинала требует новой проверки привязанных текстов. Покрытие текстами учитывается отдельно в `manufacturerTextCoverage`.

Карточка React и HTML без JavaScript показывают все подходящие записи в раскрываемых блоках с издателем, разделом и ссылкой на страницы. Существующее описание и расшифровка сохраняются.

Новые проверенные разделы добавлять без замены прежних:

```sh
node scripts/registerManufacturerTexts.js /absolute/path/curated-sections.json
```

Вход: массив записей либо `{ "records": [...] }` той же схемы. Повторное добавление тех же записей ничего не меняет. Изменённому тексту присваивается новый ID; попытка перезаписать прежний ID отклоняется. После расширения поднять ревизию базы, обновить её статистику, выполнить тесты, применить базу к прайсу через `applyDesignationKnowledge.js --apply` и пересобрать карточки. Публикация на сервер выполняется отдельно.


### Расширение до 80% описаний, ревизия 2026-10-17.8

После применения к 5708 позициям: 4567 (80,01%) имеют заводское описание или назначение; 2358 — несколько подходящих текстов. В реестре 400 записей из 66 заводских документов, в прайсе используются 387 записей. Из 400 записей 150 — техническое изложение ранее проверенных конструкционных полей; это не новые независимые документы и не дословные цитаты. Все 74 записи предыдущего реестра сохранены без изменения.

Полной расшифровке соответствуют 4322 позиции (75,72%). Цель 80% по строгому признаку `officialComplete` пока не достигнута: необходимо ещё 245 позиций. Статусы сопоставления: 4346 `reviewed`, 361 `partial`, 1001 `unresolved`. Не следует смешивать покрытие описаниями, полную расшифровку, независимую проверку и вероятность правильности.

`applicationOnly` сохраняет подтверждённое назначение семейства при неполной конструкции либо противоречивом номинале. Такое семейство имеет `dimension: unknown`, `evidence.kind: manufacturer-application-only`, обязательное предупреждение и никогда не получает `officialComplete`. Для отдельных заводских рядов проверяются размеры и количество групп, комбинированные сечения и буквенный регистр экранов. НИКИ «С» — светостойкость, а не слюдяной барьер; ПТВО «О» — ПВХ-оболочка.

`requiredFirePattern` требует явного пожарного исполнения, когда оно определяет материал; `allowedFirePattern` ограничивает допустимые варианты. `excludedFirePattern` не позволяет показывать конструкционное описание базовой ПВХ-оболочки для неподтверждённого HF-исполнения. Неизвестный цвет, индекс или продолжение марки остаются непроверенными.

В реестре явно выделены две формы заводского авторства на внешних площадках: `manufacturer-submitted-publication` (подписанные данные Подольсккабель на RusCable) и `technical-library-copy` (оригинальный каталог Кавказкабель в технической библиотеке). Сохраняются площадка, автор и `independentOfManufacturer: false`. Такие публикации не выдаются за независимые альтернативные проверки. Проверены оригиналы и SHA-256 всех 66 документов, используемых текстовым реестром.

Независимая проверка `check-064` сопоставляет базовую конструкцию ПВ4 по Рыбинсккабель и Подольсккабель; дополнительное заводское описание сохранено отдельной записью. При расширении четыре прежних результата переведены на уточнение (три МКЭфШВ и одна нестандартная конфигурация СИП-2); чистый прирост полного покрытия относительно .6 — 316 позиций.


### Справочный и нормативный слой 2026-10-20.1

`shared/designationReferenceGuides.json` хранит ПрофСектор как справочный источник с восемью областями значений. `shared/designationStandards.json` содержит десять действующих в РФ стандартов и указатель на полный постраничный корпус `data/designation-reference-corpus`. Сохранены 301 страница PDF, 16 отдельных документов изменений/поправок на 35 страницах и 30 ссылок на официальные карточки изменений. Повторные страницы исходных сборников не являются независимыми доказательствами.

Отменённые/заменённые ГОСТ Р 53768-2010 и ГОСТ 22483-2012 исключены. ГОСТ 6323-79 не используется как общий стандарт из-за ограниченной сферы действия. ГОСТ 26411-2024 не назначается автоматически до общего введения 01.07.2027; досрочное применение учитывается только при прямом указании документации изделия. Поиск исключает ГОСТ 26411-85 после известной даты замены.

Поиск: `node scripts/searchDesignationStandards.js --standard 'ГОСТ 31565-2012' --query 'дошкольных'`. Можно задавать `--topic` и `--limit`. Отдельные поправки ищутся вместе с базовым текстом. Полные тексты и OCR служат материалом для проверки; сложные таблицы и заменённые пункты не становятся автоматическими правилами без проверки контекста. Корпус не является официальной или полностью консолидированной публикацией стандартов.

Слой имеет собственную ревизию и не меняет заводские семейные правила, счётчик `officialComplete`, исходные поля прайса или изготовителя партии. Нормативные и справочные документы не добавляются в `manufacturerTexts`. Файлы прайса и товарные карточки не пересохранялись ради регистрации справочных источников.

### Полная расшифровка 80%, ревизия 2026-10-20.2

База применена к прайсу 21.10.2026: `officialComplete` — 4567 из 5708 позиций (80,01%), прирост 245 без потери прежних полных расшифровок. Назначение или описание есть у 4745 позиций (83,13%), несколько текстов — у 2393. В реестре 905 семейств и 486 текстов; все прежние 400 текстов сохранены без изменения.

Добавлено 86 документов: 71 документ изготовителей, 14 документов органов сертификации и один документ владельца марки. Последние две категории не используются как первичное доказательство полной заводской расшифровки. Из новых документов 43 используются как первичный источник полных расшифровок позиций текущего прайса. Нормативный слой сохранён отдельно.

Для коаксиальных РК теперь раздельно обрабатываются волновое сопротивление, диаметр по изоляции и код конструкции; диаметр не выдаётся за сечение. Добавлены проверки сочетаний сечения, класса жилы и напряжения НВ/НВМ, экранированных конфигураций КУП, рядов размеров и количества жил импортных кабелей. Неподтверждённые размеры, пожарные исполнения и продолжения марки не получают полный статус. Новые правила используют существующий автоматический путь импорта.

Покрытие отражает наличие документально привязанной расшифровки, а не статистическую вероятность её правильности и не установленного изготовителя конкретной складской партии. Подробности и проверка сохранности данных: [отчёт](reports/designation-full-80-2026-10-21.md).
