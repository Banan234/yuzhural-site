# База расшифровок обозначений

Версия `2026-10-14.3`. База `shared/designationKnowledgeBase.json` содержит 538 семейных записей, реестр 81 найденного документа и сведения о доступности. Собраны 58 документов, включая PDF на 3166 страниц. Наличие файла в реестре не означает ручную проверку всех его страниц. Номенклатурные перечни и совпадения в таблицах аналогов служат поисковыми подсказками, а не доказательством конструкции.

Каждая семейная запись задаёт точное обозначение, описание, значения элементов, размерную величину и источник. Новые записи содержат `evidence.documentId`, физические страницы PDF и дату проверки. Конструктор КУМП позволяет сочетать описанные в нём экраны и броню. Такие комбинации основаны на правилах конструктора; самостоятельная проверка паспорта каждого SKU не выполнялась.

Короткие обозначения изготовителей и непроверенные продолжения марки не раскрываются по общему словарю букв. Например, КСБ — имя семейства. Диаметр и сечение задаются отдельными размерными типами. У КПЭТИ размер зависит от однопроволочной или многопроволочной жилы, поэтому единица автоматически не присваивается. Документы описывают семейство и не подтверждают изготовителя складской партии.

## Применение к прайсу

Сначала выполнить просмотр:

```sh
node scripts/applyDesignationKnowledge.js --report /tmp/designation-preview.json
```

После проверки применить к локальному каталогу:

```sh
node scripts/applyDesignationKnowledge.js --apply --report /tmp/designation-applied.json
npm run build:prod
```

Операция использует блокировку импорта, создаёт резервную копию и публикует новую версию `data/catalog-current` через существующую атомарную транзакцию. К каждой позиции добавляется только `designationDecoded`; все исходные поля проверяются на полное равенство. Совместимый `data/products.json` обновляется той же транзакцией. Старый релиз сохраняется существующим механизмом каталога.

Все будущие импорты (локальный файл, удалённый прайс, загрузка через админку и плановый запуск) автоматически используют текущую базу. `classifyEligibleProducts` заполняет `designationDecoded`, а окончательный список после присвоения стабильных ID обогащается через `enrichPriceDesignations`. Перед публикацией `publishImportArtifacts` повторно применяет текущие правила, заменяя устаревшие расшифровки из входных данных. Новые SKU не требуют отдельного ручного запуска. В отчёт импорта добавляется `designationDecoding`, рядом с каталогом сохраняется `designation-coverage.json` с подсчётами и очередью нераспознанных позиций. Поле содержит версию базы, ID семейной записи, расшифровку, ссылки, нераспознанные элементы и предупреждения. API карточки сохраняет это поле. React и статический HTML используют общий построитель из `shared/productDesignation.js`, поэтому изменения справочника доступны при следующей сборке.

Статусы:

- `reviewed`: построитель нашёл семейство, распознанные атрибуты не вызвали замечаний.
- `partial`: семейство найдено, отдельные элементы или размеры требуют уточнения.
- `unresolved`: семейство не подтверждено. Показаны только независимо распознанные элементы.

Это статусы автоматического сопоставления; они не обозначают экспертную проверку партии.

Результат применения к 5708 позициям: 4289 с найденным семейством (3226 без замечаний, 1063 с уточнениями), 1419 без подтверждённого семейства. Цены, остатки, артикулы, URL и исходные наименования не меняются.

## Расширение

Добавлять сведения только по документации изготовителя: точное семейство, область действия исполнения, размерная величина и физические страницы. Для HTML указывать прямую страницу. Сохранять URL, дату получения и SHA-256 документа в реестре; недоступность отмечать отдельно. Полные PDF и текстовые выгрузки хранятся в исследовательской папке чата и не включены в репозиторий.

Сопоставление неизвестных марок с текстом документов создаёт очередь кандидатов для ручной проверки. Совпадение имени, числового артикула, таблицы аналогов или упоминания другого производителя не допускает автоматического включения в рабочие правила. После изменения базы обновить её версию, запустить тесты расшифровки и применения, проверить отчёт прайса и пересобрать HTML.

В версии .3 добавлены 14 доступных документов Камкабеля, Томсккабеля, Prysmian и Спецкабеля, 232 семейных правила. Варианты экранов ТОФЛЕКС КУ основаны на явно перечисленных заменах в конструкторе; они сохраняют положение группового и общего экрана. Суффикс напряжения принимается только для перечисленных бумажно-изолированных марок и значений из таблицы. Числовые серии ЛОУТОКС требуют контекста бренда; серия 20 измеряется сечением, 30 — диаметром. Концентрический проводник NYCY не подменяется металлическим экраном.

Полная проверка: 1012 тестов прошли; `build:prod` успешна. Контрольный переимпорт действующего прайса остановлен существующим ограничением изменения категорий (27,05% против 1%). Для проверки обработки использован только `--dry-run --override-publish-guard`, без записи или публикации прайса. Текущие расшифровки применены отдельной операцией, сохраняющей все исходные поля; категории также сохранены. Этот защитный контроль не отключён для будущих импортов.
