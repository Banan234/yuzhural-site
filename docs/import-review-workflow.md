# Проверка импорта и спорных позиций

Уведомления: при первом появлении ошибки приходит письмо с типом и последней публикацией. Повторы того же типа на том же источнике и файле подавляются до восстановления (в том числе при чередовании уже известных ошибок). Новая причина или новый файл могут дать отдельное письмо. После успешной публикации либо успешной проверки неизменившегося прайса приходит одно письмо «работа восстановлена». Обычные успешные проверки неизменившегося файла проходят без письма.

Расписание проверяет давность успешной проверки источника. PRICE_IMPORT_STALE_HOURS задаёт порог, по умолчанию 24 часа. Если прайс не менялся, но успешно проверялся, предупреждение не нужно. Время публикации в письме остаётся временем фактического обновления каталога. При отсутствии истории монитор не придумывает дату. На спящем Mac монитор не работает до пробуждения; постоянное наблюдение требует сервера.

## Очередь проверки

`npm run review:import -- export` создаёт `output/import-review.csv` (Excel, UTF-8, разделитель «;»). Содержит название, причину, коды, лист, строку Excel, категорию и исходные ячейки. Используется последний архивный отчёт с reviewRows: сетевой таймаут не уничтожает очередь. Путь к исходному HTML-отчёту печатается в консоль. Формулы из исходных ячеек экранируются.

Для подтверждённой корректировки цены:

```
npm run review:import -- price "точное название из очереди" 123.45 "обоснование из документа/прайса"
```

Сначала показывается предыдущая и предлагаемая корректировка. Для сохранения повторить с `--apply`. Перед записью создаётся резервная копия `data/priceOverrides.json.review-backup-*`; запись защищена общей блокировкой импорта. Корректировка применяется по точному названию и затрагивает все совпадающие названия; цену нужно проверить для всех таких строк. Данные очереди не изменяются этой командой и позиция не объявляется исправленной.

После сохранения запустить `npm run import:price` без `--if-changed`: вручную изменённые правила должны примениться даже при прежнем файле источника. Проверить новый отчёт, цену/единицу и исчезновение причины из очереди. Цена не решает ошибки структуры, неизвестной единицы, категории или обозначения: для них требуются изменения соответствующих правил источника/классификации, отдельная проверка и повторный импорт. Универсальное автоматическое подтверждение всех 154 строк не реализовано и недопустимо без проверки фактов.
