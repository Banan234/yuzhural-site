# Реестр независимого аудита

Актуальный указатель: `outputs/catalog-audit-state.json`. Читать progress и continuation из него перед следующим проходом. Исторические audit.json не заменять. Каталог и исследовательский handoff этим механизмом не изменяются.

`claims.py` выделяет буквальные единицы и проверяет область доказательств. Это внутренний реестр, не автоматический технический эксперт. Предложение с несколькими фактами требует ручного разделения. SOURCE_REQUIRED не равен ошибке. Подтверждение двух утверждений не подтверждает карточку целиком.

`run.py` воспроизводит только первый проход КВВГ с двумя утверждениями. Повтор на том же output завершается без записи. Это не автоматическая очередь исследования всех марок. При следующем проходе добавлять новые доказательства и сохранять старый claimsIndex: не запускать этот специализированный скрипт на новом output с прежним содержимым как новое исследование.

Для продолжения: прочитать актуальный state; сохранить предыдущие rows/reviews/findings/claimsIndex; сверить изменения текущих SKU адресно; выбрать оставшиеся утверждения из continuation; прочитать применимый первоисточник; записать отдельное scoped-доказательство с SHA-256, страницей, точным исполнением и ограничениями; применять через applicability; сохранить новый каталог аудита, отчёт и указатель атомарно. При несовпадении исходного обозначения доказательство не переносить. Два изменённых параллельно SKU 5238/5240 перепроверить адресно. Три КУПП остаются CONFLICT до паспорта/однозначного первичного подтверждения размерности.

Проверка: `python3 -m unittest discover -s tools/catalog-audit -p 'test_*.py' -v`.
