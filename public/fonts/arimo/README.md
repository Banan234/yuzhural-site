# Arimo

Arimo v36, upright variable font, weights 400–600.
Site text: 450; headings, menus and buttons: 550.

Source: https://fonts.googleapis.com/css2?family=Arimo:wght@400..600&display=swap
License: SIL Open Font License 1.1, see OFL.txt.
Cyrillic, Cyrillic Extended, Latin and Latin Extended hosted locally.

Rendering size adjustment: 108% to compensate for the smaller apparent size after switching from Noto Sans.
