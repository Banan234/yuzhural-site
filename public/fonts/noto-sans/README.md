# Noto Sans

Noto Sans v42, upright variable weight 400–600, normal width.
The site uses 450 for regular text and 550 for medium text.

Source: https://fonts.googleapis.com/css2?family=Noto+Sans:wght@400..600&display=swap

Cyrillic, Cyrillic Extended, Latin and Latin Extended subsets are hosted locally.
The Latin Extended subset includes the ruble symbol.
