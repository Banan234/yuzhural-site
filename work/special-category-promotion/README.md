# Вынос двух категорий из специальных

В основном каталоге прямо перед «Специальными кабелями» размещены:
- Кабели для подвижного состава — 57 позиций.
- Бортовые провода — 46 позиций.

В специальных осталось 4 группы, 61 позиция. Старые URL обеих вынесенных категорий сохранены. Обновлены справочник категорий, 4 правила импорта и 2 сопоставления исходных рубрик. Общая нормализация определяет новый родительский раздел для существующих товаров и следующего импорта.

Проверки: все 5708 уникальных SKU и товарные URL сохранены; изменён родительский раздел только у 103 позиций; импорт выбранных семейств согласован с текущим каталогом. 172 теста прошли, build:prod завершён. API, страницы, статические HTML, desktop/mobile меню проверены. Мобильная страница не имеет горизонтального переполнения.

Следующее возможное объединение: 3 позиции ППСРВМ из «Провода для подвижного состава» в основной раздел подвижного состава (57 + 3 = 60). Это рекомендация; в текущем изменении они сохраняют прежнее размещение.
